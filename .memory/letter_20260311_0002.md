## 3. The "Pain" Log (CRITICAL)
* **Next.js 16 middleware warning:** `middleware.ts` convention deprecated in favor of `proxy.ts`. Still works for now. May need rename in future.
* **Tailwind v4 config:** Uses `@theme` in CSS, NOT `tailwind.config.ts`. Plan was written for v3-style config — all adapters were made correctly.
* **`.env*` gitignore:** Pattern `.env*` catches `.env.example`. Added `!.env.example` exception.
* **`navigator.platform` deprecated:** TypeScript warning [6385] in `detect-os.ts` line 17. This is expected — it's the fallback for browsers without `userAgentData`.
* **[71007] warnings:** "Props must be serializable" warnings on `onClose`/`onOpenForm` props in `DemoModal`, `Pricing`, `CtaFinal`, `AirtableForm`. These are false positives — all components are consumed within client components, not at the server/client boundary.
