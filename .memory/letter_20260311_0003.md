## 3. The "Pain" Log (CRITICAL)
* **Tried:** Having root `app/layout.tsx` render `<html>` with `lang` attribute
* **Failed:** Root layout doesn't have access to `[locale]` params — can't set `lang` there
* **Workaround:** Made root layout a pass-through (`return children`), moved `<html>` + `<body>` + fonts to `app/[locale]/layout.tsx` where locale is available. This is the recommended next-intl pattern.
* *Note:* Next.js docs say root layout MUST have `<html>`/`<body>`, but next-intl pass-through pattern works in practice.
