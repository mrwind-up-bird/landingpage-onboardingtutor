## 3. The "Pain" Log (CRITICAL)
* **Tried:** Setting `lang={locale}` on `<html>` in root `app/layout.tsx`
* **Failed:** Root layout has no access to `[locale]` route params
* **Workaround:** Made root layout a pass-through (`return children`), moved `<html>` rendering to `app/[locale]/layout.tsx`. Works in practice despite Next.js docs saying root layout must have `<html>`.
* *Note:* Do not move `<html>` back to root layout — the pass-through pattern is the standard next-intl approach.
